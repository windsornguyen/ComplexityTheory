# Contributing

Thanks for helping formalize computational complexity theory in Lean.

## Before You Start

Search the existing issues, discussions, and pull requests before starting
work. Open an issue or discussion first for new foundations, public APIs,
notation, dependencies, or large formalizations.

For results taken from a textbook or paper, cite the source and state any
change in assumptions or formulation. A proof that compiles can still
formalize the wrong theorem.

## Development Setup

Install the Lean toolchain selected by `lean-toolchain`, then run:

```bash
lake exe cache get
lake build --wfail
lake lint
```

## Proof Contributions

- Reuse Mathlib definitions and theorems when they fit.
- State assumptions explicitly and keep definitions as general as useful.
- Do not use `sorry` or introduce axioms to discharge proof obligations.
- Add new public modules to `ComplexityTheory.lean`.
- Include documentation and examples when introducing public definitions.

Follow established Lean and Mathlib naming and style conventions. Prefer clear
types and explicit finite ranges over ambiguous mathematical shorthand.

## Continuous Integration

Workflow YAML is generated by Hollywood. Edit `ci/*.ts`, never the generated
files in `.github/workflows/`, then run:

```bash
npm ci --ignore-scripts
npm run generate
npm run check
```

When changing repository controls under `iac/github/`, also run:

```bash
terraform -chdir=iac/github fmt -check
terraform -chdir=iac/github init -backend=false -input=false -lockfile=readonly
terraform -chdir=iac/github validate
```

GitHub may pause workflows from external contributors until a maintainer
approves them. This is expected and does not indicate a CI failure.

## Pull Requests

Fork the repository, create a short-lived branch from `main`, and open a small,
focused pull request back to `main`. Complete the pull request template and
include the commands or evidence used to verify the change.

Pull request titles use Conventional Commits because they become squash commit
messages and drive Release Please:

```text
feat(circuits): formalize Boolean circuit evaluation
fix(reductions): preserve polynomial-time bounds
docs: clarify encoding conventions
```

If AI tools materially assisted the contribution, disclose that in the pull
request. Contributors must understand and be able to explain the code and
proofs they submit.
